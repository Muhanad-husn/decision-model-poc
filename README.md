# decision-model-poc

A proof of concept testing whether a small decision model can take over the picking that LLMs now do inside agent pipelines, at a fraction of the cost and with its doubt visible. TypeSafe's Jev (`jev-1.13.0`) is compared with Sonnet 5.5 and with the labels that already exist, on all 120 Axial passages across five coding axes and on 400 sampled CIP actor and claim classifications, against bars pre-registered before any model call. The results feed the follow-up to "The Agent Is the New User" and the CIP evidence line. The PRD is not copied here; the master lives at `D:\The Merge Seat\research\decision-model-poc\PRD.md`.
